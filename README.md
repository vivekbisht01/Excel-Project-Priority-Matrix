# 📊 Strategic Project Priority & Feasibility Matrix (Excel)

An executive decision-making framework built in Microsoft Excel to evaluate, score, and prioritize enterprise IT and operational initiatives based on **Feasibility (X-axis)**, **Impact (Y-axis)**, and **Resource Effort/Size (Bubble Size)**.

---

## 🚀 Business Context & Objective
When managing a corporate project portfolio, leadership often faces resource constraints and competing priorities. This model helps business leaders answer a critical question:  
***"Which initiatives deliver the highest strategic impact while remaining operationally feasible?"***

Designed for executive presentation, this dashboard eliminates visual clutter and provides a data-driven multi-criteria scoring matrix to optimize capital allocation.

---

## 🛠️ Technical Highlights & Dashboard Features
* **Dynamic Bubble Matrix:** Built using an advanced XY Bubble Chart to map 3-dimensional data metrics simultaneously across a 10-point scoring axis.
* **Executive Design Standards:** 
  * Applied **35% solid-fill transparency** to bubbles to ensure full data visibility even when data points overlap.
  * Hidden gridlines and custom-labeled axes for a sleek, presentation-ready layout.
* **Structured Data Architecture:** Transposed vertical data layout enabling seamless chart mapping, clean data modeling, and scalability for additional project criteria.
